# SillyTavern 记忆宫殿插件

给 SillyTavern（酒馆）接入真正的**长期记忆**——一个**纯前端插件**，无需任何外部后端或额外 Python 依赖，本地酒馆与云酒馆（Docker / Serv00 / 宝塔等）完美通用。

> 当前版本：**v2.5.0**

---

## 架构定位

纯酒馆原生方案：**无 mem0ai、无独立后端、无 localStorage**。

```
SillyTavern 前端插件（纯 JS，单文件自包含）
└── index.js
    ├── 存储层     ← 结构化分区 + 多角色隔离 + CRUD（extension_settings 服务端持久化）
    ├── 提示词层   ← 全自定义 Prompt 配置（大总结 / 待办提取，可落盘）
    ├── LLM 调用   ← 复用酒馆主模型，或可选独立外部 API
    ├── 记忆引擎   ← 阈值大总结 / 关键词+情绪标签检索召回 / 分批次总结 / 后台静默
    └── 管理面板   ← 悬浮球 + 可视化增删改查（手机/电脑响应式）
```

---

## 核心特性

### 1. 存储与架构（本地 + 云端通用）
- 纯前端插件，无 mem0ai、无 Python 后端依赖。
- **严禁 localStorage**：所有结构化记忆通过 SillyTavern 的 `extensionSettings` 持久化到服务端 `data/` 目录，云酒馆与本地酒馆都能正确落盘，多端同步、清浏览器缓存不丢失。

### 2. 多角色隔离 + 结构化分区
- 通过角色唯一标识（`角色名::characterId`）独立建档，多角色、群聊、多人卡严格隔离，换卡自动切换对应记忆。
- 核心分区：
  - **关键事件** `key_events`：每条事件独立，带 1-3 个「关键词（事件锚点）」+「情绪标签（情绪分类）」——这是记忆的基石。
  - **日记** `character_diary`：带日期的流水账，日期作为关键词触发（用于纪念日）。
  - **情感流转** `emotion_flow`：含日期区间 + 好感度百分比 + 关系定位，大总结后发送一次稳定关系级别。
  - **纪念日** `special_occasions`
  - **待办/约定** `todos`：去重 + 完成态自动识别
  - **重要物品** `important_items`：去重，格式 {name, significance}
  - **NPC 动态建档**：严格「名字-身份」命名，命中名字/身份关键词才激活发送，记忆极简。

### 3. 阈值大总结 + 分批次（不再每层总结）
- 对话达到阈值（默认 20 层）才触发一次**完整大总结**，或手动「一键总结」。
- 超过 50 层自动**分批次总结**（每批默认 25 层），避免 LLM 注意力丢失、中间内容被吞。
- 总结输出结构化 JSON，自动分门别类写入对应分区；**去重**避免跨楼层重复记录。
- **每次大总结后自动隐藏除最近 5 层外的全部楼层**（酒馆原生 `/hide` 机制，可手动恢复）。

### 4. 关键词 + 情绪标签检索召回（不一股脑全发）
- 每轮只把「命中关键词或情绪标签」的关键事件发给 AI，精准召回、不污染上下文。
- **情绪反向召回**：上下文识别到负面情绪（伤心/生气/失望…）时，自动同时触发相对的正面情绪标签（开心/温暖/幸福…）对应的事件，让角色在冲突时回忆起你的好。
- 关键词格式铁律：英文一个单词、中文 2-3 字词语，极简锚点。

### 5. 后台静默总结 + 提醒
- 总结在后台静默执行，不阻塞聊天、关闭主页面不中断。
- 成功绿框（toastr.success）、失败红框（toastr.error）提示，含具体错误原因。

### 6. 独立 API（可选）
- 默认复用酒馆主模型，无需任何额外 Key/URL。
- 也可在设置里接入独立外部 API（OpenAI/Anthropic 兼容格式），支持一键「拉取模型列表」。

### 7. 可视化管理面板
- 侧边可拖拽悬浮球（静止时只露 1/4），点击召唤档案面板。
- 所有分区内容支持手动增删改查，改动即时落盘。
- 独立「提示词配置」页，网页端直接修改所有 Prompt。
- 响应式布局，手机端（`100dvh` + 安全区适配）与电脑端均美观不拥挤。

## 存储机制说明（通用性与安全性）

本插件的**所有数据**（记忆、NPC 档案、待办、物品、提示词配置）统一写入 SillyTavern 官方的 `extensionSettings`，由酒馆自动持久化到服务端：

- 本地酒馆 → `data/default-user/settings.json`
- 云酒馆（宝塔 / Docker / Serv00 等）→ 项目目录下等价位置

因此无论换电脑、清浏览器缓存、还是切换设备访问云酒馆，只要服务器上的数据目录还在，记忆就**绝对不会丢失**。全程**不使用 localStorage**。

## 安装（一键）

在 SillyTavern 的「扩展 → **Install Extension**」中，粘贴本仓库的 URL：

```
https://github.com/badcode1024-tech/sillytavern-long-term-memory
```

（可选填分支；多用户场景可选择安装到「所有用户」或「当前用户」）

点击确认后，酒馆会自动下载并加载插件，无需任何额外配置（无后端、无 API Key），立即可用。

> 提示：安装第三方扩展需要电脑上已安装 git。

## 设置项

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 总开关 | 开 | 启用/关闭整个记忆功能 |
| 注入记忆到提示词 | 开 | 是否把记忆注入模型 |
| 总结触发阈值 | 20 | 达到该楼层数触发大总结 |
| 保留最近活跃楼层数 | 5 | 总结后保留不归档的楼层 |
| 待办检查频率 | 10 | 每 N 轮检查一次待办 |
| 分批次大小 | 25 | 超过 50 层时每批总结的楼层数 |
| 独立 API | 关 | 可选接入外部 API 单独做总结 |
